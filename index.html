Shakespeare Mini Language Model

This project showcases a compact, beginner-friendly GPT-style language model inspired by Shakespeare. It trains on character-level text patterns and learns to generate new, stylized prose.

Open Notebook Read Project Guide

What this project demonstrates

  • Character-level tokenization and vocabulary building
  • Transformer-style attention and language modeling
  • Training loops, loss tracking, and text generation
  • A practical introduction to modern AI language models

How it works

The notebook loads text, converts it into token IDs, trains a small transformer, and then generates new text from learned patterns.

Tech stack

Built with Python, PyTorch, and NumPy to keep the implementation simple and educational.

Why it matters

It is a clear, approachable example of how large language models are built from the ground up.

Created as a lightweight showcase for an AI project in the browser.
